## Project 1 - Virtual Enterprise Security Lab

**Queries:**
- Can we use pfSense?
- Is Kali Linux viable? Or a Linux workstation or web server?
- Will there be any class/course restraints?
- Are there any changes you guys would suggest?
- What times could work?
- Is there anybody you would recommend collaborating with for this project?

**Key Concepts:**
- Understanding Networking applications such as TCP/IP, DNS, DHCP, VLANs, Routing, NAT, Firewalls, and Network segmentation.
- Working through security among IDS/IPS, Network monitoring, authentication, least privilege, Segmentation, and Attack detection.
- Developing Red and Blue team responses with ample documentation. 
- Applying DFIR basics with Evidence acquisition, Disk imaging, Timeline analysis, Memory analysis, Log correlation, and Incident reconstruction.
